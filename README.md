# J.A.R.V.I.S. Releases

Offizielle, signierte Updates des lokalen Windows-Assistenten J.A.R.V.I.S.

Updates werden vor der Installation kryptografisch verifiziert. Die Anwendung lädt keine Updates ohne Zustimmung herunter.

Dieses Repository enthält ausschließlich öffentliche Release-Dateien. Keine persönlichen Daten oder privaten Signaturschlüssel hochladen.
